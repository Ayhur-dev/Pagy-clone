# 🌐 Landing Page Clone — Interactive & Animated

> **Modern UI/UX Recreation**  
> 🌐 **Live Demo:** [Visit Live Site](https://pagy-clone.vercel.app)

A pixel-perfect, fully responsive landing page clone built with Vue 3 and Vite. Focuses on seamless visual flow, clean component architecture, and fluid UI animations powered by Motion Vue and Lucide icons.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Vue 3 (Composition API)
* **Build Tool:** Vite
* **Routing:** Vue Router
* **Styling:** Tailwind CSS
* **Animations:** Motion Vue
* **Icons:** Lucide Vue Next
* **Deployment:** Vercel

---

## ✨ Key Highlights

* **Responsive Design:** Adaptive layout grid engineered with Tailwind CSS, optimized across mobile, tablet, and desktop viewports.
* **Fluid Animations:** Smooth entry reveals, scroll-driven motion, and interactive hover effects built with Motion Vue.
* **Component Architecture:** Modular, reusable Vue components designed for maintainability and performant rendering.
* **Modern Iconography:** Clean vector icon integration powered by Lucide Vue Next.
